## 产品边界

CodeXPedal 是安静的额度监视工具。macOS 与 Windows 是两套原生界面，不把 Windows 任务栏机制照搬进 Mac Dock，也不保留旧 Mac 仪表盘。

## macOS：A 横向极简条

- 常驻主界面是系统菜单栏和可选 NSPanel 横条。
- 横条按顺序显示 5小时（存在时）、7天（存在时）、右侧为成功快照 HH:mm:ss 或带周期的下次重置时间。
- 仅有一个窗口时自然收窄；不要空轨道、固定三栏、月额度或用套餐名称猜测。
- 没有成功数据时显示“额度 --”与“--:--:--”；官方明确不提供支持窗口时详情解释原因。
- 紧凑横条不放图标、品牌名、副标题、刷新按钮、“刚刚更新”或 Token 统计。
- 旧快照数字带 ≈，不能把失败或过期伪装为实时。详情与 tooltip 同步展示来源、成功时间和失败原因。
- 菜单栏仅用系统尺寸，宽度贴合实际读数：等宽数字保证同位数刷新不抖动，只有位数或 ≈ 标记变化时宽度才变；浮窗字号 20–42pt 可调。
- 详情／设置单独按需打开；只显示菜单栏时仍可访问，不弹出大型仪表盘。
- 同时启用 Codex 与 Claude 时，横条上下两行、每行左侧名称，字号为设置值的0.8倍（不低于20pt）；菜单栏缩写为“名称 5小时%/7天%”。只启用一项时使用完整字号；两项关闭显示「没有可获取的 AI」。

## 视觉与交互

- 使用系统字体与等宽数字；关键百分比显著于周期标签，时间略小但清晰。
- 浮窗颜色锚点为石墨、白和青绿，青绿 `#56D6B5` 表示额度数据；旧值用中性白并附 ≈。
- 原生 NSVisualEffectView 单层材质，静态边框与阴影；不增加粒子、持续呼吸、光斑或装饰渐变。
- 不使用 emoji 图标；应用图标仅在系统资源和适合的详情／设置位置使用，不放回横条。
- 单击菜单、双击浮窗详情、拖动浮窗；键盘和 VoiceOver 能理解周期、剩余及状态。
- 多显示器变化时将窗口限制在可见屏幕，用户位置保留；不覆盖其他应用的菜单栏。

## Windows

保留既有 TrafficMonitor 式 WPF 紧凑层级、动态额度、任务栏与通知区域行为。同时启用 Codex 与 Claude 时，悬浮窗两行（左侧名称标签），任务栏上下两行（字号约为任务栏高度三成，10–14 DIP），托盘提示两行；只启用一项时占满原单行空间；两项关闭时保留空态和设置入口。任务栏必须预留真实空间，无法安全占位时隐藏，不得遮挡其他软件。

Windows 任务栏的时间列只显示时间值，跨天仍显示日期；重置模式不显示「5时重置」或「7天重置」前缀。悬浮窗、托盘提示和详情保留原说明。

<!-- [AI修改] 额度时间下拉框使用专用样式，不改变其他系统控件。 -->
设置中的「额度时间显示」收起区与展开列表均为深灰底、浅色字；选中与悬停使用蓝灰底，禁用时保持深色并降低透明度，键盘焦点通过边框显示。

## 隐私与验收

不展示prompt、回复、tool arguments、原始日志或个人完整路径。Windows原有本地Token聚合估算仅在详情中区分来源，不当成官方额度；Mac不引入此统计。原型标注演示数据，HTML不能替代原生、真实额度与能耗验收。

新规范不承诺旧仪表盘、配色包、领导力或自动更新；Claude 只显示额度，不增加 Claude 会话统计面板。历史设计资料仅供追溯，不覆盖本规范。
