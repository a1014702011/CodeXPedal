# 共享核心与平台边界

<!-- [AI修改] 记录实际复用接口，不把共享测试样例冒充共享生产代码。 -->

`shared/src/lib.rs` 是唯一的额度业务实现。Windows P/Invoke加载同次构建的DLL，Mac通过唯一C头链接同一源码生成的静态库。界面、CLI路径发现、进程管道、设置和系统生命周期留在各平台。

| 共享入口 | 责任 |
|---|---|
| pedal_parse | 官方result/本地桶解析、桶选择、严格数字、窗口分类/去重/排序 |
| pedal_remaining | 剩余百分比，拒绝无效数字 |
| pedal_apply | 只有合法成功结果替换拓扑和时间，失败保留旧快照 |
| pedal_is_stale | 错误、采样年龄、窗口复位和时钟倒退的统一判断 |
| pedal_abi_version | 宿主启动时核对布局版本 |

输入最多1MiB，serde JSON有递归限制；窗口最多2个。C ABI使用固定宽度字段，Window=24字节、Snapshot=64字节；内存由调用方持有，没有跨语言释放或回调，panic不会跨过解析ABI。指针有效性仍由宿主负责，不接受不可信原始指针。

300分钟为5小时，10080分钟为7天；未知时长忽略，明确空响应是有效快照，不强制要求7天。多桶视图存在时只认codex，不从旧桶补数据。百分比必须有限且在0–100；剩余为100减已用。失败不更新时间，不跨事件拼接。

宿主DTO只是界面适配，不得重新实现上述业务判断。本地JSONL只适配事件外壳，额度字段也调用同一解析器。新规则先在共享核心测试，再验证两个真实绑定。

构建依赖由Cargo.lock锁定。开发需要Rust，用户不需要；Windows静态链接MSVC运行库，Mac静态链接共享核心。原生UI、系统版本和运行时仍需分别验证。
