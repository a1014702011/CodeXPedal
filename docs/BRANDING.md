CodeXPedal 最初参考了 [shanggqm/codexU](https://github.com/shanggqm/codexU) 的额度处理思路。当前 macOS 原生界面与共享业务核心已重写，Windows 客户端独立实现；活动工程不再包含旧 Mac 客户端、配色包、徽章或其发行说明。

CodeXPedal originally referenced the quota-handling approach of shanggqm/codexU. The active native macOS client and shared business core have been rewritten; the Windows client is independently implemented. Historical Mac implementation/resources and release records are not shipped.

[TrafficMonitor](https://github.com/zhongyang219/TrafficMonitor) 仅作为任务栏与紧凑呈现的参考，没有复制其源代码或资源。保留根MIT许可证及必要版权，不把旧实现清理理解为删除版权或声称全部原创。

产品名称、应用标识和软件包统一为CodeXPedal。独立图标不是OpenAI官方图标。旧品牌环境变量、配置迁移与注册表兼容代码已移除，但不删除用户磁盘数据。
